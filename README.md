# Boni Exit Exam

An interactive Management / Business Management / Business Administration exit-exam practice website.

## Features
- Multiple question banks
- Random question selection across all papers
- Selectable exam length
- Countdown timer with automatic submission
- Practice mode with immediate answer feedback
- Question navigator and flagging
- Results summary and answer review
- Responsive layout for phones, tablets, and desktops
- No server or database required

## Run locally
Open `index.html` in a modern web browser.

## Publish online with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `boni-exit-exam`).
2. Upload `index.html` and `README.md` from this folder to the repository's **root**.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site. The public website link will appear in the Pages section. It usually looks like:
   `https://YOUR-USERNAME.github.io/boni-exit-exam/`

## Important notes
- The website is hosted online, but the exam itself runs in the visitor's browser.
- The question bank and answer key are included in `index.html`; visitors can potentially inspect them. This is suitable for practice, not a secure high-stakes examination.
- Scores are not automatically sent to you or stored in a central database. Each visitor sees their own result on their device.
- The app does not require an internet connection after the page has loaded, but the GitHub Pages website needs internet to be opened initially.
- Check the answer key carefully before using the questions for an official assessment.
